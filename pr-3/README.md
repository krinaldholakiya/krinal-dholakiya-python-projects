# 📌 Overview

The **Student Data Organizer System** is a menu-driven Python console application designed to manage student records efficiently using Python data structures.

This project allows users to:

* ➕ Add new student records
* 📋 Display all students
* ✏️ Update student information
* 🔍 Search for students
* ❌ Delete student records
* 📚 Display all offered subjects

The application demonstrates practical use of:

* Lists
* Tuples
* Sets
* Dictionaries
* Loops
* Match-case statements
* Conditional logic

---

# 🎯 Project Objective

The main objective of this project is to build a beginner-friendly student management system using Python.

This project helps students understand:

| Concept         | Usage                          |
| --------------- | ------------------------------ |
| 📋 Lists        | Store multiple student records |
| 📦 Tuples       | Store Student ID and DOB       |
| 📚 Sets         | Store unique subjects          |
| 📖 Dictionaries | Store student details          |
| 🔄 Loops        | Continuous menu execution      |
| ⚡ Match Case    | Handle user menu choices       |
| 🔍 Searching    | Find student records           |
| ✏️ Updating     | Modify existing details        |

# 🧠 Concepts Used

## 📋 List

Used to store all student records.

```python
students=[]
```

---

## 📦 Tuple

Used to store Student ID and Date of Birth.

```python
student_tuple=(myid,dob)
```

---

## 📚 Set

Used to store unique subjects.

```python
subject_set=set(subject.split(","))
```

---

## 📖 Dictionary

Used to organize student details.

```python
student_data={
    "student_id,dob":student_tuple,
    "name":name,
    "age":age,
    "grade":grade,
    "subjects":subject_set
}
```
